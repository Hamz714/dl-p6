**Rulings:**
- **Weight sharing inside `forward`: allowed, in this form only.** Reuse the same block's weights at several depths inside one feed-forward pass from (x_t, t) to the output. Shared-weight depth is standard (ALBERT, Universal Transformer) and keeps one network call per sampler step. **Not allowed:** feeding the full network's output back into itself, i.e. running the whole denoiser iteratively inside `forward`. That's extra network evaluations per step in disguise.
- **Self-conditioning: not allowed.** `forward` would carry state between the sampler's calls, which changes the effective sampler.
- **t-dependent experts: allowed** (architecture, one call per step).
